# qiayun-admin 项目架构分析

## 📊 项目概览

**qiayun-admin** 是一个基于 Vue3.4 + TypeScript + Vite5 + Element-Plus 的现代化后台管理系统模版，使用最新技术栈开发，提供了完整的管理后台解决方案。

## 🏗️ 技术架构

### 核心技术栈

- **前端框架**: Vue 3.4 (Composition API + `<script setup>`)
- **开发语言**: TypeScript
- **构建工具**: Vite 5.3.2
- **UI 框架**: Element-Plus 2.7.6
- **状态管理**: Pinia 2.1.7 + 持久化插件
- **路由管理**: Vue Router 4.4.0
- **HTTP 客户端**: Axios 1.7.2 (二次封装)
- **图表库**: ECharts 5.5.1
- **国际化**: Vue-i18n 9.13.1

### 开发工具链

- **代码规范**: ESLint + Prettier + Stylelint
- **提交规范**: Husky + Commitlint + czg
- **包管理器**: pnpm
- **CSS 预处理**: Sass
- **图标方案**: SVG Icons + Element Icons

## 📁 核心目录结构分析

### 1. API 层 (`src/api/`)

```
api/
├── config/          # API 配置
│   └── servicePort.ts    # 服务端口配置
├── helper/          # 请求拦截器和工具
│   ├── axiosCancel.ts    # 请求取消管理
│   └── checkStatus.ts    # 状态码检查
├── interface/       # 接口类型定义
│   └── index.ts          # 全局接口类型
├── modules/         # 按模块分组的 API
│   ├── login.ts          # 登录相关接口
│   ├── upload.ts         # 文件上传接口
│   └── user.ts           # 用户相关接口
└── index.ts         # Axios 封装主文件
```

**核心特性**：

- 完整的请求/响应拦截器
- 自动 loading 控制
- 错误状态码统一处理
- Token 自动注入
- 请求取消机制

### 2. 组件层 (`src/components/`)

```
components/
├── ProTable/        # 🌟 核心表格组件
├── SearchForm/      # 搜索表单组件
├── Upload/          # 文件上传组件
├── ECharts/         # 图表组件
```
