# HiMorning应用技术架构设计

## 🏗️ 技术架构概览

### 架构模式
**单体架构（Monolithic Architecture）**
- 早期快速开发和部署
- 简化运维复杂度
- 便于功能迭代和调试

### 技术栈选择

#### 后端服务
- **框架：** NestJS v10.x
- **ORM：** Prisma v5.x
- **数据库：** MySQL 8.0
- **身份验证：** JWT + Passport
- **文件存储：** 阿里云OSS / 腾讯云COS
- **缓存：** Redis 7.x
- **任务队列：** Bull Queue (Redis)

#### 前端应用
- **框架：** Flutter
- **状态管理：** Zustand / Redux Toolkit
- **UI组件：** 自定义组件库
- **HTTP客户端：** Axios

#### 第三方服务
- **短信服务：** 阿里云短信 / 腾讯云短信
- **微信登录：** 微信开放平台
- **AI服务：** OpenAI API / 文心一言
- **推送服务：** 极光推送 / 友盟推送

### 1. 用户认证模块 (AuthModule)

#### 功能职责
- 用户注册/登录
- 手机验证码验证


## 🔐 安全设计

### 身份验证流程

#### 手机验证码登录
```
1. 用户输入手机号
2. 系统发送6位数字验证码（5分钟有效）
3. 用户输入验证码
4. 验证成功后生成JWT Token
5. 返回Access Token + Refresh Token
```

#### 微信授权登录
```
1. 前端调用微信SDK获取授权码
2. 后端通过授权码获取用户信息
3. 检查用户是否已注册
4. 未注册则自动创建用户
5. 生成JWT Token返回
```

### JWT Token设计
```typescript
interface JwtPayload {
  sub: number;        // 用户ID
  phone?: string;     // 手机号
  wechatId?: string;  // 微信ID
  iat: number;        // 签发时间
  exp: number;        // 过期时间
  type: 'access' | 'refresh';
}
```
