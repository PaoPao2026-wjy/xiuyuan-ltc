# HiMorning应用原型稿

## 📱 项目概述

这是HiMorning应用的HTML+CSS+JavaScript原型稿，基于原型页面说明文档创建，展示了应用的完整用户界面和交互功能。

### 🎯 设计理念
- **积极阳光** - 温暖的色彩搭配和正向的内容引导
- **温柔舒缓** - 圆润的设计元素和流畅的交互体验  
- **自然清新** - 清新的视觉风格和舒适的用户界面

## 🚀 快速开始

### 运行方式
1. 下载所有文件到本地文件夹
2. 使用现代浏览器打开 `index.html` 文件
3. 推荐使用手机模拟器或调整浏览器窗口至移动端尺寸（414px宽度）

### 文件结构
```
原型稿/
├── index.html      # 主页面文件
├── style.css       # 公共样式文件
├── pages.css       # 页面专用样式
├── app.js          # 交互功能脚本
└── README.md       # 说明文档
```

## ✨ 功能特性

### 🌅 早晚打卡页
- **图片上传** - 点击上传区域选择图片，支持实时预览
- **心语输入** - 200字限制的文本输入，实时字数统计
- **心情选择** - 6种心情状态选择（开心、平静、疲惫、兴奋、思考、感恩）
- **完成打卡** - 带动画效果的打卡确认功能
- **历史记录** - 可折叠的历史打卡记录查看

### 📰 热点内容页
- **分类筛选** - 4个内容分类（今日推荐、心理健康、生活方式、个人成长）
- **资讯卡片** - 图文结合的新闻展示卡片
- **内容预览** - 标题、摘要、分类和时间信息
- **点击交互** - 卡片点击反馈和跳转提示

### 🤖 AI心语页
- **角色切换** - 3个AI角色（温柔小语、阳光小伙伴、智慧大哥哥）
- **聊天界面** - 气泡样式的聊天对话框
- **消息发送** - 支持文本输入和Enter键发送
- **AI回复** - 智能模拟回复，多样化响应内容
- **语音功能** - 语音按钮（功能提示）

### 👤 个人中心页
- **用户信息** - 头像、昵称、打卡统计展示
- **数据图表** - 7天心情变化可视化图表
- **设置选项** - 通知提醒、偏好主题、分享成长等设置入口
- **信息编辑** - 点击昵称可编辑用户名

## 🛠️ 开发说明

### 自定义修改
1. **颜色主题** - 修改 `style.css` 中的 `:root` 变量
2. **页面内容** - 编辑 `index.html` 中的对应区域
3. **交互逻辑** - 在 `app.js` 中添加或修改功能函数
4. **样式调整** - 在 `pages.css` 中修改页面专用样式

### 扩展功能
- 添加数据持久化（localStorage）
- 集成真实的API接口
- 增加更多页面和功能模块
